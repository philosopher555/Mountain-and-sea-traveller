# 山海之外：雾岛来信

一款原创山海题材的浏览器像素冒险。画面由 Canvas 与 CSS 实时绘制，不依赖图片素材。

## 运行

需要 Node.js 18 或更新版本：

```sh
npm start
```

打开 `http://localhost:4173`。部署到同一台可公开访问的 Node 服务器后，多位玩家用相同的“同行暗号”即可进入同一房间。

## GitHub Pages

本仓库已配置 GitHub Actions：推送到 `main` 后自动发布到 [GitHub Pages](https://philosopher555.github.io/Mountain-and-sea-traveller/)。Pages 是静态托管，支持单人游戏；多人功能需要运行 `server.mjs` 的 Node 服务。

## 第一章

- 进入时选择旅人衣裳，并可设置旅人名字和同行暗号。
- 探索芦苇渡口、悬藤谷、云上石庭与夜潮祭坛，聆听场景故事并收集潮光。
- 四个区域住着 16 位各有故事的居民；部分居民会委托收集潮光，交还后可领取额外奖励。
- 上下穿行不同层路，靠近才显现 12 件秘境遗物；调查可阅读专属线索并拾得潮光。
- 每件遗物除潮光外还会补充可使用的工具充能：寻潮螺定位最近遗物、藤铃提示当前回声、云羽短时加速高跳、潮灯短时显出本区全部遗物；点击工具栏或按 1–4 使用。
- 遗物会补充四种可用工具：寻潮螺定位遗物、藤铃提示回声、云羽加速高跳、潮灯短时显物；点击快捷栏或按 1–4 使用。
- 在每处地标记忆潮音方向序列，解开回声才能开启下一道雾门；无失误通关可获得额外潮光。
- 用潮光在潮汐山货铺购买皮肤；金币、衣箱和拾取进度保存在当前浏览器。
- 桌面使用 WASD / 方向键移动、E 交谈、空格跳跃；触屏使用虚拟摇杆与动作按钮。
- 第二章按钮展示“更新中”页面。

多人状态通过同源 HTTP 轮询同步。玩家房间数据只保存在服务进程内，服务重启后清空；当前原型不提供账号系统或服务端权威存档。
